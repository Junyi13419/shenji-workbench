# 神机 · SHENJI — 综合资源工作台

一个**单文件、零构建、开箱即用**的综合资源工作台，聚合免费 Token 活动、免费服务器/域名资源、社区邀请码、GitHub 趋势、优质 Skill 与教程、AI 资讯与变现思路，并提供定时同步巡检、链接可用性巡检与本地快照兜底。支持云端账号同步与本地数据备份。

暗金风格的单页应用，数据全部内联，**双击 `index.html` 即可在浏览器中运行**，无需安装任何依赖。

- 在线演示：<https://shenji-resource-workbench.app.workbuddy.host/>
- 开源协议：[MIT](./LICENSE)

## 🚀 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/Junyi13419/shenji-workbench.git
   cd shenji-workbench
   ```
2. 直接用浏览器打开 `index.html` 即可使用。
3. 也可用任意静态服务器托管（**小豆码池的本地快照走 fetch，需经 HTTP 访问才生效**）：
   ```bash
   python -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```

## ☁️ 云端同步（可选）

应用接入 WorkBuddy Cloud，提供云端账号、数据存储等能力：

- 在**个人中心**登录后，资料、领取记录等数据可同步到云端，跨设备保持一致。
- 云端能力通过 CDN 加载的 SDK 与 OAuth 中继完成，**代码中不含任何内嵌密钥**，密钥由登录态动态获取。
- 不想使用云同步也完全可以：所有数据默认保存在浏览器 `localStorage`，纯本地运行。

## 🔐 管理模式

顶栏的「登录同步 / 导出备份 / 导入备份 / 添加活动 / 联系我」等管理类按钮**默认对普通用户隐藏**，仅管理员可见。

开启管理员模式：在 3 秒内连续点击左上角**品牌栏 5 次**即可切换，状态保存在本地。

## 🗂 目录结构

```
shenji-workbench/
├── index.html            # 主应用（单文件，含全部样式、脚本与内联数据）
├── xiaodou-codes.json    # 小豆码池本地快照（定时更新，远端故障时的兜底数据源）
├── data.js               # 历史数据源快照（仅供参考，主页面不依赖）
├── assets/               # 图标、二维码等静态资源
├── README.md
└── LICENSE
```

> 说明：`index.html` 已将资源数据全文内联为 `window.TOKEN_WORKBENCH_DATA`，**主页面完全自包含**，不依赖 `data.js`。`data.js` 是早期数据源的留存副本，可能落后于主页面，请勿据此判断当前数据。小豆码池的 `xiaodou-codes.json` 为独立快照文件，由定时任务从社区公开数据源同步。

## 🔄 数据更新机制

- **资源数据**：每日 00:00 定时任务全网搜索 8 类资源，去重后写入 `index.html` 的内联数据块，自检修复并同步 GitHub 与线上。
- **小豆码池**：页面实时 fetch 社区数据源（定时刷新），首次加载先读 `xiaodou-codes.json` 快照秒开；每 2 小时定时任务更新快照并同步线上。远端不可达时保留快照数据，不会空白。

## 🤝 贡献

欢迎提交 Issue 或 Pull Request。注意事项：

- 资源数据请改 `index.html` 中 `window.TOKEN_WORKBENCH_DATA` 的内联数据块（不要改 `data.js`，它是历史快照）。
- 新增条目需按板块字段规范填写，避免重复（`provider/fullName/name/title` + `url` 双重比对），并填写 `discoveredAt`。
- 提交前确认无密钥、账号密码、个人隐私信息；临时文件与备份文件已被 `.gitignore` 排除。
- 涉及交互改动请验证 7 语言 i18n 键完整。
