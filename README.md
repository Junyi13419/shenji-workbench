# 神机 · SHENJI — 综合资源工作台

一个**单文件、零构建、开箱即用**的综合资源工作台，聚合免费 Token 活动、AI 资讯、GitHub 趋势、优质 Skill 与教程，支持云端账号同步与本地数据备份。

暗金风格的单页应用，数据全部内联，双击 `index.html` 即可在浏览器中运行，无需安装任何依赖。

## ✨ 功能一览

| 板块 | 说明 |
|------|------|
| **Token 活动** | 聚合各大平台的免费 Token / API 额度活动，支持领取进度记录 |
| **资源合集** | 长期有效或永久的优质资源，按类目浏览 |
| **AI 资讯** | 每日 AI 行业新闻时间线，可搜索、按时间筛选 |
| **GitHub 趋势** | 每日 / 每周热门仓库，一键复制 AI 解读提示词 |
| **技能 Skill** | 精选优质 Skill，提供安装命令与安全风险 AI 解读 |
| **学习教程** | 分难度、语言、格式筛选的学习资源 |
| **变现指南** | C 端 / B 端变现思路与破局建议 |
| **项目展示** | 内置与自定义项目卡片，登录后可增删 |
| **个人中心** | 资料表单、头像、三级地区联动、昵称表情选择器、书签自动填充 |
| **数据备份** | 一键导出 / 导入本地备份（管理员模式） |

## 🚀 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/Junyi13419/shenji-workbench.git
   cd shenji-workbench
   ```
2. 直接用浏览器打开 `index.html` 即可使用。
3. 也可用任意静态服务器托管，例如：
   ```bash
   python -m http.server 8000
   # 浏览器访问 http://localhost:8000
   ```

## ☁️ 云端同步（可选）

应用接入了 [WorkBuddy Cloud](https://www.workbuddy.cn)，提供云端账号、数据存储等能力：

- 在**个人中心**登录后，资料、领取记录等数据可同步到云端，跨设备保持一致。
- 云端能力通过 CDN 加载的 SDK 与 OAuth 中继完成，**代码中不含任何内嵌密钥**，密钥由登录态动态获取。
- 不想使用云同步也完全可以：所有数据默认保存在浏览器 `localStorage`，纯本地运行。

## 🔐 管理模式

顶栏的「登录同步 / 导出备份 / 导入备份 / 添加活动 / 联系我」等管理类按钮**默认对普通用户隐藏**，仅管理员可见。

开启管理员模式：在 3 秒内连续点击左上角**品牌栏 5 次**即可切换，状态保存在本地。

## 🗂 目录结构

```
shenji-workbench/
├── index.html          # 主应用（单文件，含全部样式与脚本、内联数据）
├── data.js             # 数据源（活动/资讯/技能/教程等，可单独维护）
├── assets/             # 图标等静态资源
├── README.md
└── LICENSE
```

> 说明：`index.html` 已将 `data.js` 的数据全文内联，因此**主页面完全自包含**，不依赖外部数据文件。`data.js` 作为数据源单独保留，便于维护与变体页面引用。
